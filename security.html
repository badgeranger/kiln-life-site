Data and security

Use less access. Keep control visible.

The exact tools and controls are agreed before confidential data or production systems are involved.

Default approach

Start with synthetic, redacted or aggregated information. Add access only when the agreed decision requires it.

Kiln does not claim ISO 27001, SOC 2 or another formal security certification.

1. Minimum data

Only the fields needed for the agreed dashboard are used.

2. Agreed tools

Data sources, cloud services and AI providers are named before use.

3. Limited access

Permissions are time-bounded and limited to the relevant workspace or source.

4. No public reuse

Client confidential information is not used for public examples or Kiln-owned model training.

5. Human review

AI-written analysis is a draft. Calculated facts and business judgment stay separate.

6. Clear exit

Return, retention and deletion expectations are agreed for the project.

Before access

Five facts are written down.
